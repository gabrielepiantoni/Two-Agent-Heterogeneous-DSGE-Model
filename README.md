# Two-Agent-Heterogeneous-DSGE-Model
This repository contains a macroeconomic research project implementing and estimating a dynamic stochastic general equilibrium (DSGE) model with heterogeneous households. The model distinguishes between two types of agents: hand-to-mouth households, who consume their current income each period, and optimizing households, who smooth consumption intertemporally through saving and capital accumulation. The framework is developed within a standard neoclassical production environment with stochastic total factor productivity.
The theoretical structure of the model is derived analytically and implemented computationally using Dynare and MATLAB. The repository includes several Dynare model files defining alternative specifications of the model, including a baseline version and detrended variants used to obtain a stationary representation consistent with balanced growth. The model incorporates deterministic trend growth and stochastic productivity shocks, and it is solved around its stationary steady state.
The project is organized in three main components. First, the theoretical model is derived and analyzed, including the household optimization problems, firm behavior, government sector, aggregation conditions, and the steady-state characterization of the detrended economy. Second, the dynamic properties of the model are studied through impulse response functions following productivity shocks, illustrating the transmission mechanisms across output, consumption, investment, wages, and capital accumulation. Third, the model parameters are estimated using two complementary approaches: Simulated Method of Moments (SMM) and Bayesian estimation. The estimation relies on quarterly U.S. macroeconomic data obtained from the FRED database, including real GDP, real consumption, and short-term interest rates.
The repository contains the Dynare model files (.mod), auxiliary include files used to modularize the model structure, MATLAB scripts for data construction and preprocessing, and input datasets in .mat format. Additional scripts generate impulse response functions, estimation outputs, and diagnostic plots. The full theoretical derivations, estimation procedures, and empirical results are documented in the accompanying LaTeX report.
